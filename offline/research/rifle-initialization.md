## Cosmetic var 49 binding frame

The native variable-binding reader is `sub_7FF6D1C2D4F0`, called from `sub_7FF6D1C2D2C0`. It reads a compact binding count, then a compact parameter count per binding. A zero parameter count has no parameter pairs. The next selector chooses an explicit signed compact instance ID or the current owner context. The parser's frame-mode byte at `+0x4C` then selects state resolution: set means read an index using graph width `+0x170` and resolve against the explicit runtime instance; clear means use graph width `+0x174` and resolve through the current graph's state table. This byte is set by the independent frame-header mode bit in `sub_7FF6D1BD4160`, not by the binding record itself. The update tail is branch-dependent: when the float-present bit is zero, the reader defaults the float and consumes only the priority-present bit; it does not consume the update bit. Three zero tail flags therefore encode the default values.

For graph 596, the live header widths are `+0x170 = 7` and `+0x174 = 6`. The `StateBound(Entity(0), instance=1, state=11, state_bits=7)` var 49 binding encodes to 20 bits: outer count `10` (2), parameter count zero (1), explicit-instance selector (1), positive signed compact instance 1 (6), state index 11 (7), and three zero tail flags (3). Native acceptance confirmed the binding: var 49 changed from undefined (kind 255) to kind 7 with value `0xB00010001`, representing a state reference to instance 1/state 11. In a separate runtime capture, manager state 38 created the 2BC UI root and crosshair; ten shots reduced ammo and removed/respawned the bot while manager and body states persisted. The accepted var 49 state reference and the crosshair/shooting results are separate observations; a visible weapon cosmetic from this binding is not yet confirmed.

The apply path is `sub_7FF6D2DC78A0` → `sub_7FF6D2DC7420` → `sub_7FF6D2D94DE0`: it compares parsed binding records with the CVar's current binding list, rebuilds that list when changed, then stores each resolved source-state pointer with its binding metadata. This explains why var 49 resolves to a state reference rather than remaining the serialized fallback entity value. Native function addresses are from the local 1.74 image snapshot, base `0x7FF6D1220000`.
