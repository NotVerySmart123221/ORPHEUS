# Retail 1.74 roster animation audit

Tested all 32 selectable heroes on retail `1.74.0.0.104319` against the local Practice Range server. The capture series contains 32 fire trials and 52 reload trials at 32.1–37.5 fps. Every fire trial used a 150 ms left click and a 160 ms right click. Each ammo-limited kit had one reload with a 20-damage hit at about 0.5 s and one with an ability input during the reload. The server logged both mouse inputs for every hero and the intended event for every reload trial. Each capture ZIP has input marks, frame timestamps and its server log slice.

The table records first-person observations. A server shot, muzzle effect, or camera movement alone does not establish an authored weapon pose. Hold, charge, aim and target-dependent paths remain open where the tap was inconclusive. The default loaded kit was used, including pilot D.Va and staff Mercy.

The 24 visible standard reloads did not show a clear return to the start pose after the hit. Ability captures showed reload motion and, in some cases, an overlapping cast. A short overlay can obscure an exact frame comparison. Soldier has a separate control and two ability comparisons in [Reload refresh](reload-refresh.md). The roster run used the lobby from before the new ammo-free fix. The automated roster test verifies that primary input keeps ammo-free capacity intact and R leaves the reload timer unset. It also checks reliable body deltas during every served cooldown for finite kits.

All 32 first-person asset roots were inspected. Direct, unambiguous shared aliases with matching clip timing yielded pairs for Hanzo, Symmetra, Zarya, Lúcio and Brigitte. The hand-verified Soldier reload pair remains available. Blender 5.2 imported Hanzo's paired clips and rendered from the bow clip. A separate Reaper render assigned the same weapon clip to two distinct gun actions on the left and right hardpoints. These are clip pairing checks. Runtime fire and reload selection still depends on the native state machine.

The Assault result lock passed for all 32 kits in server tests. Each test submitted movement, primary, secondary and melee after a result, then verified input acknowledgement and unchanged movement and combat state. The earlier Hanamura retail test reached the result and timed menu return. Roster captures were in Practice Range, so they do not cover a live Assault round for each hero.

Raw frames are under `.scratchpad/roster-retail/` and can be cleared. The client and lobby logs are in [the launch directory](main-menu/20261104T175556.997771Z/).
